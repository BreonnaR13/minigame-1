# Minigame 1
## Devlog

Components, game objects, and scenes can be compared to a bakery! Components are the attributes that make up game objects. If game objects are baked goods, the components would be details like its taste, appearence, and cost. 


The same way components make up game objects, game objects make up scenes. The game objects would be the baked goods where as the scene would be the bakery. Within the bakery, the baked good can, for example, be bought or served.
